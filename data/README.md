# Datos del proyecto - Juegos Olimpicos

Por tamano y buenas practicas, los archivos CSV originales no se suben a GitHub.

## Como descargar los datos
1. Ingresa al dataset de Kaggle: **120 years of Olympic history: athletes and results** (https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results).
2. Descarga y descomprime los archivos.
3. Coloca los siguientes dos archivos directamente dentro de esta carpeta `data/`:
   * `athlete_events.csv`
   * `noc_regions.csv`
