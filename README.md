# Taller Pandas: 120 Anos de Historia Olimpica (1896 - 2016)
Analisis exploratorio con Pandas para Programacion II.
## Integrantes y Roles
- Julian Andres Velandia Cortes (Lider de Datos, Repositorio y Reporte)

## Objetivos del trabajo
* Cargar, explorar y limpiar los conjuntos de datos de atletas y regiones olimpicas.
* Analizar valores faltantes, crear nuevas variables (IMC, medalla, n_pruebas y grupo_etario) y verificar hipotesis mediante conteos y tasas proporcionales.
* Generar graficos e interpretaciones claras que permitan responder que perfil de atleta tenia mayor probabilidad de ganar una medalla.
* Aplicar un flujo de trabajo colaborativo en GitHub usando ramas, commits claros, Pull Requests y resolucion de conflictos.

## Como ejecutar el proyecto
1. Clonar este repositorio en el computador local.
2. Descargar los archivos `athlete_events.csv` y `noc_regions.csv` desde Kaggle siguiendo las instrucciones de `data/README.md` y guardarlos en la carpeta `data/`.
3. Instalar las librerias necesarias (`pandas` y `matplotlib`).
4. Abrir y ejecutar el cuaderno `notebooks/proyecto_olimpiadas.ipynb` o el script `src/analisis_olimpiadas.py`.

## Estructura
- `data/`: Instrucciones de descarga de datasets.
- `notebooks/`: Cuaderno principal con el analisis.
- `outputs/`: Tablas y graficos generados.
- `docs/`: Informe final en PDF.
